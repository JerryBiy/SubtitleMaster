# Netflix Subtitles+

Netflix Subtitles+ lets you watch Netflix with external subtitle files when the built-in subtitles are unavailable in your language — and it can now **find those subtitles for you online**.

Instead of modifying Netflix's player, this extension renders subtitles as an overlay on top of the video — similar to professional subtitle tools — so it works reliably across movies, episodes, fullscreen mode, and Netflix's dynamic interface.

## 🎬 Who is this for?

- Viewers watching Netflix through VPNs with missing subtitle languages
- Language learners using custom or translated subtitles
- Users who want more control over subtitle timing and appearance

## ✨ Key Features

### 🔍 Find subtitles online

Search multiple subtitle providers (OpenSubtitles, Assrt, and Subdl) directly from the player and load a result with one click — no manual downloading required.

- Automatically detects the current title, season, and episode
- Looks up cross-language title variants (via Wikipedia) so it finds subtitles even when a show is listed under a different name in your region
- Prioritizes the English title for the best match rate, with native-language titles as fallbacks
- Filters out unrelated results so you see only subtitles for the title you're watching

### 📂 Load external subtitles

Upload your own `.srt` or `.vtt` subtitle files directly from the extension.

### ⏱ Automatic synchronization

Subtitles stay in sync with playback using the video's current time.

### 🎯 Fine-grained timing controls

Adjust subtitle offset in milliseconds or use keyboard shortcuts:

- `[` shift subtitles earlier
- `]` shift subtitles later
- `\` reset timing

### 🎨 Fully customizable appearance

- Font size
- Vertical position
- Background opacity

### 💾 Per-title and global settings

Save preferences for individual videos or apply them across all titles.

## 🔒 Privacy & Safety

- No tracking, analytics, or ads
- No subtitle hosting or redistribution
- Subtitle files are processed locally in your browser
- Settings are stored locally using Chrome storage
- Online searches are sent only to the chosen subtitle providers to look up and download the file you select

## ⚠️ Important Notes

- This extension does not modify Netflix's built-in subtitles.
- Online search results come from third-party subtitle providers; their availability and accuracy are not guaranteed.
- You must provide or use subtitle files you are authorized to use.
- Netflix content is protected by copyright; this tool only overlays subtitle text.
